# Context Onion RFCs

RFCs are durable proposals for the Context Onion model, its terminology, and its reference guidance. They record a problem, a proposed direction, significant design decisions, and questions that remain open.

## Statuses

Project status (Context Onion lifecycle):

- **Draft** — open for discussion and revision; not yet stable project guidance.
- **Accepted** — adopted as part of the project's current reference model.
- **Superseded** — replaced by a newer RFC; retained for historical context.

AAIF track (ecosystem acceptance; separate from project status):

- **Not submitted** — no AAIF project proposal has been filed.
- **Under review** — a proposal is before the AAIF Technical Committee.
- **Accepted** — AAIF has accepted the work; cite the decision.

A Community Draft Specification may be fully adoptable while still Draft and while the AAIF track remains Not submitted. Project status changes and AAIF track changes should each be explicit in a pull request and preserve the prior document's history. Do not claim AAIF endorsement without an AAIF decision.
