# Context Onion RFCs

RFCs are durable proposals for the Context Onion model, its terminology, and its reference guidance. They record a problem, a proposed direction, significant design decisions, and questions that remain open.

## Statuses

- **Draft** — open for discussion and revision; not yet stable guidance.
- **Accepted** — adopted as part of the project's current reference model.
- **Superseded** — replaced by a newer RFC; retained for historical context.

The status appears near the top of each RFC. A status change should be explicit in a pull request and preserve the prior document's history.
